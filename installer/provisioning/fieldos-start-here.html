Reference

A small English Wikipedia archive, two CDC source documents on emergency water and food safety, and a text-only National Weather Service tornado-safety reference are included. This is a limited starter set, not a comprehensive repair, medical, or emergency library.

Maps

Low-zoom world and sample U.S. map data is included for orientation and testing. It is not suitable for street, trail, parcel, or navigation decisions.

Why some catalog items are missing

Project N.O.M.A.D. can offer additional archives, detailed map regions, software updates, and other optional downloads. Those catalog downloads require a separate internet-connected update session. Other FieldOS content packs can be transferred by USB and installed without internet.

The included CDC PDFs and text-only NWS tornado reference are source-attributed and added to N.O.M.A.D.'s local Knowledge Base. They are not comprehensive emergency guidance and do not provide live weather alerts. Open the originals and check current local authorities; generated answers may still be wrong and are not a substitute for medical or safety references.

Add an optional regional map without internet

Map packs are separate files and are not included in this test edition. Obtain the archive and its matching .sha256 file from a source you trust on another computer, then copy both to a USB drive.

  1. Open the USB drive in Files and note its name.
  2. Open Terminal and install the pack. Replace USB-NAME and the archive filename with the names shown on your drive:
    sudo /opt/fieldos/scripts/fieldos-content-packs.py install "/media/$USER/USB-NAME/map-pack.tar.zst"
  3. Wait for the command to report activated map, then open or reload Maps in the Command Center. The imported region appears there without a service restart.

The installer checks the bundle checksum, manifest, and artifact hashes before storing it. A checksum does not establish that a publisher or license is trustworthy; review the pack's source and attribution. PMTiles packs activate in Maps. PDF and text source packs appear in the Source Library above. Other pack types remain stored but may not yet integrate with an application.

Add reference documents from a content pack

Use the same verified USB transfer and install command above with a reference-pack archive. After the installer reports activated reference documents, run sudo python3 /opt/fieldos/scripts/fieldos-nomad-index-references.py to add its PDFs and text documents to N.O.M.A.D.'s Knowledge Base. Wait for each document to report indexed chunks. Open Source Library from this page to check the originals, source, and license. AI answers can still be incorrect; use the source documents as authority.
