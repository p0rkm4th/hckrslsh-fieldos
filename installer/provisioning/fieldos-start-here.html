Local AI

Project N.O.M.A.D. uses the bundled chat and embedding models. FieldOS blocks common emergency, medical, water-treatment, food-safety, and evacuation questions from AI chat after the test model produced unsafe answers. For those topics, read the original offline references.

Reference

A small English Wikipedia archive, CDC water and food sources, NWS-based weather summaries, the 2023 NIOSH heat-illness first-aid reference, and the 2026 Southeastern vegetable crop handbook are included. This is a limited starter set, not a comprehensive repair, medical, or emergency library.

Maps

World overview data covers zoom levels 0–5. Detailed road, water, town, and land-use data covers Tennessee and a border buffer through zoom 13. It is not turn-by-turn navigation and does not provide GPS positioning.

Why some catalog items are missing

Project N.O.M.A.D. can offer additional archives, detailed map regions, software updates, and other optional downloads. Those catalog downloads require a separate internet-connected update session. The optional CDC practical-skills checklist and other reviewed FieldOS packs can be transferred by USB and installed without internet.

Core source documents are indexed in N.O.M.A.D. and remain available in the Source Library. The NIOSH heat-illness reference is worker-focused; the vegetable handbook is regional guidance, not a Tennessee-specific calendar. These materials are not comprehensive emergency, agricultural, or medical guidance, and do not provide live alerts. CDC, NIOSH, NOAA/NWS, Virginia Tech, and Virginia Cooperative Extension do not endorse FieldOS. AI safety filters are imperfect. Open original documents and consult appropriate current guidance.

Add an offline content pack

Verified map and reference packs can be copied to a USB drive or local folder. Keep both files together in the same folder: the archive (for example, pack.tar.zst) and its exact checksum sidecar (pack.tar.zst.sha256). Open FieldOS Install Content Pack from Applications, choose the .tar.zst archive, and approve the administrator prompt.

  1. Open Files and browse to the USB drive or folder that contains the pack archive.
  2. Open FieldOS Install Content Pack from Applications → Utilities, choose the archive, and authenticate when prompted. FieldOS verifies the checksum and manifest before installation.
  3. For a map pack, open or reload Maps; for a reference pack, use the Source Library and N.O.M.A.D. Knowledge Base. The importer reports when indexing finishes.

A valid checksum confirms file integrity, not trustworthiness or redistribution rights. Review the pack's source, date, and license. Open original source documents when safety decisions depend on them; AI summaries can be incomplete or incorrect.
